# Maintainers

Telemetry Change Guard is currently in a transparent single-maintainer phase.
This file lists people with repository decision and merge authority; it does
not list occasional contributors or advisors.

| Maintainer | Role | Scope |
| --- | --- | --- |
| [Sai Kiran Taduri](https://github.com/tadurisaikiran) | Lead maintainer | Repository-wide |

## Responsibilities

Maintainers are responsible for:

- protecting deterministic and fail-closed safety contracts;
- reviewing changes, tests, compatibility, and release evidence;
- keeping decisions and known limitations public;
- triaging issues and security reports;
- enforcing the Code of Conduct; and
- cutting releases according to the documented release process.

## Becoming a maintainer

Maintainer status is earned through sustained, reviewable project work. A
candidate should demonstrate sound judgment across multiple contributions,
help review or support other contributors, understand the safety model, and
consistently follow the Code of Conduct.

An existing maintainer nominates a candidate in a public issue or pull request
that summarizes the candidate's contributions and proposed scope. Active
maintainers decide by consensus. While the project has only one maintainer,
the lead maintainer records the decision and rationale publicly.

The project will add an external-review requirement for major architectural
changes only after a legitimate additional maintainer is active. It will not
create nominal maintainers to satisfy a governance appearance.

## Inactivity and removal

A maintainer may step down at any time. After six months without project
activity, the project may ask whether the maintainer wants to become emeritus.
Maintainer access may be removed for security risk, repeated Code of Conduct
violations, or sustained failure to perform the role. Except for urgent
security access removal, the reason and decision are documented publicly.

Security reports and sensitive conduct reports follow
[`SECURITY.md`](SECURITY.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), not
public issue discussion.
